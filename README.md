# DevOps FastAPI Test App

Простое HTTP-приложение на FastAPI

## Описание проекта
Приложение предоставляет базовые эндпоинты для проверки состояния сервиса:
- GET / — Приветственное сообщение.
- GET /health — Проверка работоспособности системы ({"status":"ok"}).
- GET /info — Метаданные приложения (имя, версия, порт).
- GET /about — Информация о DevOps-тесте (добавлено через feature-ветку).

## Как запустить локально
1. Создать виртуальное окружение: python3 -m venv venv
2. Активировать: source venv/bin/activate
3. Установить зависимости: pip install -r requirements.txt
4. Запустить: uvicorn main:app --host 0.0.0.0 --port 8000

## Трудности и их решения

1. Проблема с правами в Debian: При первой попытке обновить пакеты команда sudo apt update выдавала ошибку. Переключился на root (su -), добавил пользователя в группу администраторов командой usermod -aG sudo test и перезагрузил ВМ.
2. Конфликты имён в Docker: При перезапуске контейнеров вручную возникала ошибка занятого имени. Проблема решена настройкой Systemd-сервиса, куда добавили команду ExecStartPre=-/usr/bin/docker rm -f my-fastapi-container для очистки старых процессов перед стартом.
3. Синтаксис YAML в GitHub Actions: Первые прогоны падали с ошибкой парсера из-за неверных отступов. Пайплайн был переписан с соблюдением строгого синтаксиса, а личный токен скрыт за безопасной системной переменной ${{ secrets.GITHUB_TOKEN }}.
4. Отсутствие Dockerfile в облаке: Сборщик падал с ошибкой no such file or directory. Файлы Dockerfile и .dockerignore были добавлены в индекс Git командой git add, закоммичены и запушены на GitHub.
5. Ограничение прав токена GitHub: GitHub отклонял пуш в папку воркфлоу. В настройках токена на GitHub была вручную довыставлена галочка workflow.
